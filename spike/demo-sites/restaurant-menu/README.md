# Restaurant Menu Demo

A demo restaurant website for the EmDash CMS, showcasing menu management, dietary tags, and reservation booking integration.

## Setup

1. Ensure EmDash is configured with the appropriate template.
2. Set up a PostgreSQL database and set the `DATABASE_URL` environment variable.
3. Run the development server:

```bash
npm run dev
```

## Features

- Menu categories (Appetizers, Mains, Desserts)
- Menu items with prices and descriptions
- Dietary tags (Vegan, Vegetarian, Gluten-Free, Dairy-Free, Spicy)
- Reservation booking form with date, time, and guest selection
- Integration with booking module for reservations

## Menu Categories

- **Appetizers:** Calamari Fritti, Bruschetta, Spicy Tuna Tartare
- **Mains:** Grilled Salmon, Chicken Parmigiana, Mushroom Risotto, Spicy Thai Curry
- **Desserts:** Tiramisu, Vegan Chocolate Cake
